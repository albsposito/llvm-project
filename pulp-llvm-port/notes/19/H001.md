## Why this is equivalent

Candidate failures and fork inventory checks remain independent. lit.sh accepts the file as optional sixth argument; default behavior is unchanged. Hash syntax is checked mechanically; provenance semantics require independent review.

## What breaks if this is wrong
Wrong identity evidence could misattribute coverage. Tests exercise valid mapping, missing/failed/skipped destinations, invalid evidence, duplicates, present sources, unrelated failures and fork inventory preservation. All 18 harness tests and bash -n pass. The real round-1 comparison drops from fourteen to six problems, removing precisely eight stale identities; all six failures remain.
